# Football Match Analyzer (JSON Edition)

Football Match Analyzer is a personal portfolio project developed in Python.

The goal of this project is to analyse football matches using structured JSON data and automatically generate match reports, statistics and event timelines.

## Current Status

- Phase 1 – JSON Data Modelling
- Phase 2 – Python Backend
- Phase 3 – HTML/CSS Interface
- Phase 4 – Django Integration
- Phase 5 – API Edition
